# คู่มือผู้ใช้

## ผู้ดูแลระบบ

สร้างบัญชี Admin ผ่านคำสั่ง CLI ที่ interactive แล้วเข้าสู่ระบบเพื่อสร้าง Staff และหมวดหมู่ ผู้ดูแลดู Dashboard รายงาน และแบบประเมินได้ทั้งหมด

## เจ้าหน้าที่

เปิดเมนูแบบประเมิน เลือกสร้าง กำหนดชื่อ หมวดหมู่ และกลุ่มเป้าหมาย บันทึกก่อนเพิ่มคำถาม เลือกประเภทคำถามและระบุแต่ละตัวเลือกคนละบรรทัด ตรวจทาน แล้วเผยแพร่ ระบบแสดงลิงก์และ QR ดาวน์โหลด PNG ได้

หลังเผยแพร่หรือมีคำตอบ ระบบล็อกคำถามเพื่อคงความถูกต้องของข้อมูลย้อนหลัง เปิดรายงานเพื่อดูยอดตอบ คะแนน คำตอบข้อความ ส่งออก CSV หรือสั่งพิมพ์จาก Browser

## ผู้ตอบ

สแกน QR Code เลือกประเภทผู้ตอบ กรอกคำถามที่มีเครื่องหมาย * แล้วส่ง ระบบแสดงหน้าขอบคุณเมื่อบันทึกสำเร็จ ชื่อและอีเมลไม่บังคับ
